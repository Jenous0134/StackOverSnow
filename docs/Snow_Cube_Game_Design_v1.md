# Snow Cube - Game Design Document

## 1. 개요

**Snow Cube**는 테트리스에서 영감을 받은 2D 퍼즐 게임이다.

하지만 목표는 줄을 삭제하는 것이 아니라 **눈 큐브를 이용해 얼음줄(Base
Line)을 계속 만들어 나가는 것**이다.

게임은 겨울밤의 차분한 분위기 속에서 진행되며, 퍼즐성과 힐링 감성을
동시에 추구한다.

------------------------------------------------------------------------

# 2. 장르

-   2D 퍼즐
-   캐주얼
-   힐링
-   서바이벌(게임 오버까지 진행)

------------------------------------------------------------------------

# 3. 게임 목표

플레이어의 목표는 다음과 같다.

-   얼음줄을 최대한 많이 생성한다.
-   Height를 최대한 높인다.
-   Game Over를 최대한 늦춘다.

------------------------------------------------------------------------

# 4. 기본 플레이

-   일반적인 테트리스와 동일한 7종 테트로미노 사용
-   블록은 4개의 큐브로 구성
-   조작
    -   좌우 이동
    -   회전
    -   빠른 낙하

------------------------------------------------------------------------

# 5. 큐브

## Snow Cube

기본 큐브.

시간이 흐르면서 상태가 변화한다.

    Stage 0
    ↓

    Stage 1

    ↓

    Stage 2

    ↓

    Stage 3

    ↓

    Stage 4

    ↓

    삭제

-   삭제 시 간단한 파티클만 출력
-   녹는 애니메이션은 사용하지 않음

------------------------------------------------------------------------

## Ice Cube

가로 한 줄이 완성되면 해당 줄 전체가 Ice Cube로 변경된다.

특징

-   시간 변화 없음
-   삭제되지 않음
-   영구 구조물

------------------------------------------------------------------------

# 6. 얼음줄

얼음은 큐브 단위가 아니라 **줄(Line)** 단위로 동작한다.

아래를 지탱하는 눈 큐브가 모두 사라질 경우

얼음줄 전체가 한 줄 단위로 아래로 이동한다.

개별 큐브는 떨어지지 않는다.

------------------------------------------------------------------------

# 7. Base Line

Base Line의 정의

> 아래에 눈 큐브가 없는 가장 높은 얼음줄

Base Line은 현재 플레이의 기준 바닥이다.

------------------------------------------------------------------------

# 8. Base Line 변경

새로운 Base Line이 생성되면

-   Base Line 갱신
-   배경을 한 줄 아래로 이동
-   모든 얼음줄을 한 줄 아래로 이동

플레이어는

> 한 층 올라간 것처럼

느끼게 된다.

------------------------------------------------------------------------

# 9. Camera

카메라는 플레이어를 따라가지 않는다.

항상 다음 두 기준 사이를 보여준다.

-   상단 : Game Over Line (고정)
-   하단 : Base Line (화면 바닥)

Base Line이 변경될 때만 월드가 이동한다.

------------------------------------------------------------------------

# 10. Game Over

Game Over Line은 항상 화면 상단의 동일한 위치에 존재한다.

다음 중 하나라도 Game Over Line에 닿으면 게임 오버.

-   Snow Cube
-   Ice Cube

------------------------------------------------------------------------

# 11. Height

Height는

생성된 Base Line(얼음층)의 개수를 기반으로 계산한다.

즉,

새로운 Base Line이 생성될 때마다 Height가 증가한다.

------------------------------------------------------------------------

# 12. UI

## Title

-   Snow Cube 로고
-   Game Start
-   Settings

배경은 실제 게임에서 사용하는 눈 오는 마을이다.

Game Start를 누르면

배경은 그대로 유지한 채

UI만 사라지고 게임이 시작된다.

## In Game

-   Height
-   Pause

최소 UI만 표시한다.

# 15. 배경

하나의 긴 세로 월드.
